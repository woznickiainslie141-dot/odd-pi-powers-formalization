## 0. 一句话结论

当前框架（嵌套对数 Hermite–Padé + 极小多项式结果式转移）给出
`E_k = m(D+G)/(D-(k-1)G)`，它**恒有 `E_k ≥ m`**，而且 `D - (k-1)G > 0` 迫使 `m` 很大（π³ 当前 `m = 186`）。
所以：

- 在现有转移结构内，π³ 只能做“百分比级”的改进（参数/形状优化、算术因子 γ 加强），不可能接近 100。
- 高次幂（k = 5,7,9）的上界由增长常数 `ρ = 2·exp((V-γ*)/S)` 控制（当前 ρ ≈ 4.6934），
  其中 `V = Σv_j`、`S = Σv_j c_j`。**ρ 的形状优化是一个精确线性规划**（γ 关于权重是凹分段线性的），
  已实测：L=99 时全局最优 ρ = 4.5624，且随 L 增大缓慢下降（外推极限约 4.45–4.50）。
  这对 k=9 只是约 1.3–1.5 倍级别的改进，**不是数量级改进**（初稿中的猜测已更正）。
- 已实测：π³ 只需把同一证明框架下的参数换成 `L=99, t=0..27, ν=(64,4,…,4), m=171`，
  浮点值即为 **E₃ ≈ 1107.93**（原文 1203.97，改进约 8%），Arb 证书见第 3 节。
- 想把指数里的 `m` 降为约 `m/k`，需要把辅助多项式“消元”到 `Q(i)[λ^k]`；
  朴素 Siegel 引理在最坏情形恰好退化回现有结果式界，真正的增益取决于一个**零点估计/逐次极小平衡**问题。
  这是结构性突破口，也是真正的研究难点。

## 4. 结构性分析：E_k ≥ m 从哪里来，能否去掉（第一轮手算，待核查）

### 4.1 损失的来源

转移引理 5.1 的下界是 `1 ≤ |a|^{deg U} · |U(y)| · ∏_{ℓ≥2}|U(y_ℓ)|`，其中 `|a| ≤ 2^k q`、`deg U = m`。
于是有两项损失：

- `q^m`：**首项系数的 m 次方**，它直接给出 `E_k ≥ m`；
- `e^{(k-1)Gn}`：k−1 个共轭点 `ζy` 处 U 并不小，只能用高度界，这就是间隙里的 `-(k-1)G`。

十二层 π³ 例子的分解：`D = 651.30, G = 255.60, D−2G = 140.10`，
`E₃ = m·(D+G)/(D−2G) = 186 × 6.473`。两个因子都需要压缩。

### 4.2 已排除的“免费”改进（手算结论）

- **列整除 `d_n^{m-j}`**：系数 `A_{h,j}` 的确多含 `d_n^j`，但把它吸收进变量 `Z = d_n Y` 后，
  极小多项式首项仍是 `2^k q`，常数项变成 `p d_n^k`，结果式下界完全不变。只要求值点不是“近整的”，列整除不带来增益。
- **改求值点到 `ζ_8`（log = iπ/4）等更接近 1 的单位根**：D 约增加 `M log 2`，
  但系数落在 `Z[ζ_8]`，范数要从 `Q(ζ_8, θ)` 取到 `Q(i)`，共轭数从 k 变为 2k：
  首项系数因子从 `q^m` 变为 `q^{2m}`（下限变成 `E ≥ 2m`），间隙再损失约 `kG ≈ 5.1M`（k=3），得不偿失。
- **Machin 型分解**（`λ = 4 log((5+i)/(5−i)) − log((239+i)/(239−i))`）：在本文的 `x^z` 型积分里，
  `x₁^{4z} x₂^{-z} = i^z`，系数与在 `x=i` 求值完全相同，没有任何变化。
  只有换成 Hata/Salikhov 那类“路径积分 + 特殊端点”的构造才可能利用 Machin 型公式。

### 4.3 消元思路（C1）：把辅助多项式压到 `Q(i)[λ^k]`

记 `c = y^k = i^k p/(2^k q) ∈ Q(i)`，把 `U_h(Y)` 按指数模 k 分解：
`U_h(Y) = Σ_{r=0}^{k-1} Y^r V_{h,r}(Y^k)`。找整向量 `x ∈ Z[i]^{m+1}` 使
`Σ_h x_h V_{h,r}(c) = 0（r = 1,…,k−1）`，则 `U_x(ζ^l y) = V_{x,0}(c)` 对所有 l 相同，
共轭点**不再大**，Liouville 只需对一个 `Q(i)` 中的数做，分母只有 `(2^k q)^{m/k}`。

- 约束数 k−1，未知数 m+1，解格秩 `m+2−k`，余体积约 `(q^{m/k} e^{Gn})^{k-1}`。
- “坏”向量（`V_{x,0}(c)=0`）恰好是 `U_x` 被 `Y^k − c` 整除的那些，构成解空间中的一个超平面。
- **最坏情形**：前 `m+1−k` 个逐次极小都落在坏超平面里，只能用第 `m+2−k` 个极小向量，
  其高度只能用余体积 `q^{m(k-1)/k} e^{(k-1)Gn}` 控制。代入后**恰好还原现有的结果式界**
  `m(D+G)/(D−(k−1)G)`。所以朴素的 Siegel/Bombieri–Vaaler 消元不会更差，但也不会自动更好。
- **均衡情形（启发式）**：若逐次极小大致均衡，`|x| ≈ (q^{m/k}e^{Gn})^{ρ'}`，`ρ' = (k−1)/(m+2−k)`，则
  `E_k^{bal} = (m(1+ρ')/k) · (D+G)/(D − ρ'G)`。
  当 m 很大时它趋于 `(m/k)(1+G/D)`。十二层参数下约为 `62 × 1.39 ≈ 86`；
  甚至经典平衡构造（M≈12–15）代入后约为 15。**这个数小得不可信**，说明“极小均衡”本身就是难点：
  它等价于一个带高度的非退化/零点估计，强度接近我们要证明的结论。
- **所需的新引理（研究目标）**：对所有充分接近 `π^k` 的 `p/q`，解格中存在一个非坏向量，
  其高度 `≤ (q^{m/k}e^{Gn})^{θ}`，`θ < k−1`。任何 `θ < k−1` 都严格改进现有指数；
  `θ = ρ'` 就是均衡情形。

### 4.4 两个合理性检查（手算）

- **k = 1**（逼近 π 本身，无需消元）：公式退化为 `m(D+G)/D`。平衡构造在 M = 6 时约为 20，
  与 Mignotte (1974) 的 `μ(π) ≤ 20` 量级一致，说明本框架的归一化是对的。
- **k = 2 在 x = −1 处**：系数是有理整数，`R(−1) = P_even(π²) + iπ·P_odd(π²)`，
  复共轭恰好实现 `λ ↦ −λ`，所以模 2 消元是**免费且严格的**：B 可逆推出偶数列满秩，非零性自动成立。
  得到 `μ(π²) ≤ (m/2)(D'+G')/D'`（`Θ = π`），平衡构造约为 25（已知最好结果是 Zudilin 的 5.095，并不矛盾）。
  对奇数 k，`λ ↦ ζ_k λ` 没有对应的算术自同构，这正是奇数次幂困难的根源。

浮点核对（`experiments/sanity_k1_k2.py`，仅作合理性检查，不是证书）：

| 情形 | 公式 | 浮点最优值 | 说明 |
|---|---|---|---|
| k=1, x=i, 平衡 | `m(D+G)/D` | 19.974（M=6） | 与 Mignotte 的 μ(π)≈20 一致，归一化正确 |
| k=2, x=−1, 平衡 | `⌊m/2⌋(D'+G')/D'` | 23.135（M=14） | 宇称消元，论证待 T1 核查 |
| k=2, x=−1, 两层嵌套 L=39 | 同上 | 17.664（ν=(4,1×8), m=11） | 同上 |
| k=3, 均衡极小**启发式** | `(m(1+ρ')/3)(D+G)/(D−ρ'G)` | 14.80（平衡 M=15） | **非严格**，只说明消元问题的“价值” |
| k=3, 均衡极小**启发式**，十二层参数 | 同上 | 87.64 | 对照严格结果式界 1203.97 |

解读：严格结果（1108）与均衡启发式（约 15）之间相差近两个数量级，几乎全部来自
`q^m` 与 `e^{(k-1)Gn}` 两项。**能否证明消元格中存在高度受控的非坏向量，是本课题中价值最大的单一问题。**

另一条看似可行的路 `μ(π³) ≤ 2μ(π⁶)`、再用 x=−1 处 π² 的整系数形式逼近 `π⁶=(π²)³`：
仍要对 `(p/q)^{1/3}` 做 3 次结果式，得到 `m(D'+G')/(D'−2G')`，其中 Θ=π 使 D' 更差，所以不如直接在 x=i 处做。

### B 层：加强算术（中风险，需要新引理）

- **B1 求值后的额外整除**。原稿 3.3 节末已承认 Π_n 只是系数级下界。若 `A(i)` 在 p ≡ 1 (mod 4)

  先做精确实验（工作流 N3），再找机制（`i ≡ r (mod 𝔭)`，`A(i) ≡ A(r)`）。
- **B2 Rhin–Viola 型对称化**。对 ζ(2)、ζ(3) 的测度改进主要来自这一类群作用下的额外整除。
  需要先给本文的 log 型积分找一个非平凡的变换群，可行性未知。
- **B3 有效性**（不改指数，但让结论“显式”）：给出显式 `q₀(ε)` 需要显式 PNT 余项
  （Dusart 型 θ(x) 界）以及把所有 `o(n)` 项显式化。属于工作量问题，不是研究难点。

### C 层：改变转移结构（高风险，唯一能大幅改进的路线）

- **C1 消元到 `Q(i)[λ^k]`**（见 4.3–4.4）。理论价值上限：严格指数里的 `m` 变为约 `m/k`，
  且共轭点的 `(k−1)G` 损失消失。缺口是一个精确的“非坏短向量”引理。可执行的第一步：
  小参数下用 LLL 精确构造消元格，统计短向量是否落入坏超平面、逐次极小是否均衡。
- **C2 固定次数（Type II / 多重正交多项式）**：针对 `1, λ, λ², λ³` 或稀疏的 `1, λ³` 直接构造。
  难点：x = i 离 1 太远（|i−1| = √2），需要 Hata/Salikhov 型“特殊路径积分 + 代数端点”。
- **C3 β(3) 二元线性形式**：附录 B.2 的导数核 δ < 0。需要更好的分母控制
  （very-well-poised 超几何、Ball–Rivoal 型交错构造）。即使成功，也要先确保只保留 β(3)，不混入 β(1)=π/4。
