## 1. 消元格的严格定义、秩与余体积（proved）

**分解。** 对 `x∈Z[i]^{m+1}` 令 `U_x=Σ_h x_h U_h=Σ_j u_j Y^j`，按 `j mod k` 写
`U_x(Y)=Σ_{r=0}^{k-1} Y^r V_{x,r}(Y^k)`，`V_{x,r}(Z)=Σ_s u_{ks+r} Z^s`，`deg V_{x,r} ≤ d_r:=⌊(m-r)/k⌋`。
设 `ζ=e^{2πi/k}`，则 `U_x(ζ^l y)=Σ_r ζ^{lr} y^r V_{x,r}(c)`（离散 Fourier 变换，矩阵可逆）。

**格。** `Λ={x∈Z[i]^{m+1}: V_{x,r}(c)=0, r=1..k-1}`，坏子格 `B={x∈Λ: V_{x,0}(c)=0}`。
乘以 `Q^{d_r}` 后条件变为 `Σ_h x_h w_{h,r}=0`，`w_{h,r}=Σ_s a_{h,ks+r}(i^k p)^s Q^{d_r-s}∈Z[i]`。
由 `|p|≤4Q`（因 `|p/q-π^k|<1` 且 `π^k+1<2^{k+2}`）得 `|w_{h,r}| ≤ C_m Q^{d_r} e^{(G+η)n}`。

**秩（proved）。** 由命题 2.3，`A(i)` 可逆，故 `x↦U_x` 是 `Q(i)^{m+1}→Q(i)[Y]_{≤m}` 的同构。
`m≥k-1` 时，测试多项式 `Y^r (0≤r≤k-1)` 说明泛函 `U↦V_r(c)` (r=0..k-1) 在 `Q(i)[Y]_{≤m}` 上线性无关。因此
`rank_{Z[i]}Λ = m+2-k = d`，`rank B = d-1`。

**坏 ⇔ 被 `Y^k-c` 整除（proved）。** `c≠0` 时 `ζ^l y` 是 `Y^k-c` 的 k 个不同根；Fourier 矩阵可逆，故
`V_{x,r}(c)=0 ∀r ⇔ U_x(ζ^l y)=0 ∀l ⇔ (Y^k-c) | U_x`（在 `Q(i)[Y]` 中）。由 Gauss 引理，等价于本原多项式
`f=(Q/g)Y^k-(i^k p/g)`（`g=gcd_{Z[i]}(Q,p)`，`|g|≤2^k`）在 `Z[i][Y]` 中整除 `U_x`。

**余体积（proved）。** 实化 `Z[i]^{m+1}≅Z^{2(m+1)}`：每个复条件给出两条互相正交、同范数的整行
`(Re w,−Im w),(Im w,Re w)`。`Λ=Z^{2(m+1)}∩W^⊥`，`W` 为这些行张成的有理子空间。用
`det(Z^N∩W^⊥)=det(Z^N∩W) ≤ det(行格) ≤ Π‖行‖`（Hadamard）得
`Vol_C(Λ):=det_R(Λ)^{1/2} ≤ Π_{r=1}^{k-1}‖w_{·,r}‖ ≤ C·Q^{σ}e^{(k-1)(G+η)n}`，
`σ=Σ_{r=1}^{k-1}d_r`。计数恒等式 `Σ_{r=0}^{k-1}(d_r+1)=m+1` 给出 `d_0+σ=m+1-k`，即 `σ=m+1-k-⌊m/k⌋ ≤ m(k-1)/k`。
（例：m=186,k=3 时 σ=122，主文档的近似 `m(k-1)/k=124`。）

**复逐次极小（proved）。** Λ 是 Z[i]-模，乘 i 保范数，故实逐次极小成对相等：`λ_{2j-1}=λ_{2j}=μ_j`，
`μ_j` 为 Q(i)-线性无关意义下的复逐次极小。Minkowski 第二定理：`Π_j μ_j^2 ≤ 2^{2d}det(Λ)/vol(B^{2d})`，
结合 `μ_j≥1` 得 `μ_d ≤ C_d·Vol_C(Λ)`。`μ_1..μ_d` 的达成向量 Q(i)-线性无关，不可能全在 `B⊗Q(i)`（维数 d-1）中，
故**存在好向量 `x∈Λ\B`，`|x|≤C·Q^{σ}e^{(k-1)(G+η)n}`**。

## 2. 任务 1(a)：最坏情形——主文档说法需更正，并得到一个严格小改进

**定理 A（proved）。** 在定理 1.1 的假设下（实际只需 `G+η>0` 与 `Δ_k=D-(k-1)G>0`，且 `m≥k-1`），
`μ(π^k) ≤ (m+1-k)(D+G)/(D-(k-1)G)`。

证明。取 §1 的好向量 x，`|x|≤X:=C Q^{σ}e^{(k-1)(G+η)n}`。
1. `U_x(y)=V_{x,0}(c)≠0`，且 `Q^{d_0}V_{x,0}(c)∈Z[i]\{0}`，故 `|U_x(y)| ≥ Q^{-d_0}`。
2. `|U_x(λ)| ≤ (m+1)X e^{-(D-η)n}`，`|T_x(y)| ≤ (m+1)X e^{(G+η)n}`（引理 4.1 的一致界，`|y|<2`）。
3. 取 `n` 为 L 的倍数且最小满足 `(m+1)X e^{-(D-η)n} ≤ ½Q^{-d_0}`，即
   `n ≈ ((d_0+σ)log Q + O(1))/(Δ_k-kη) = ((m+1-k)log Q+O(1))/(Δ_k-kη)`。
4. 除差恒等式给 `|λ-y| ≥ ½Q^{-d_0}/((m+1)X e^{(G+η)n}) ≥ c·Q^{-(m+1-k)}e^{-k(G+η)n}`。
   代入 n：指数 `= (m+1-k)[1 + k(G+η)/(Δ_k-kη)] = (m+1-k)(D+G)/(Δ_k-kη)`。
5. 其余（`|π^k-p/q| ≥ 2π^{k-1}|λ-y|`、令 η→0）与原稿 §5.2 完全相同。∎

**对主文档 §4.3 的判定。** "最坏情形恰好还原结果式界 `m(D+G)/(D-(k-1)G)`" —— **refuted（不精确）**。
逐项核对：q 的总指数是 `d_0+σ=m+1-k`（Liouville 用的 `Q^{d_0}` 加上 |x| 中的 `Q^{σ}`），而结果式界是 `Q^m`；
e 的指数两者都是 `(k-1)G`（共轭点大小 ↔ 余体积中的 `e^{(k-1)Gn}`）。所以最坏情形比原结果式界**严格好**
`(m+1-k)/m` 倍。原因：消元后 `U_x(y)` 落在 `Q(i)` 中，`Q^{d_0}` 足以清分母；结果式的范数分母在 `k|m` 时确实达到
`a^m`（`U=Y^m` 即为例子），因此原稿的结果式界本身不能这样改进，改进来自换用消元。
