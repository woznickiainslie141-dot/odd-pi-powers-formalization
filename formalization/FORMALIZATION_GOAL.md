# Goal specification: formalizing explicit irrationality-exponent bounds for odd powers of pi

本文件是供后续 `/goal` 任务使用的完整目标规格与实施计划。它本身不表示形式化已经开始，也不表示稿件中的结论已经获得 Lean 验证。

## 0. 可直接启动的目标描述

在当前工作区建立可独立构建的 Lean 4 项目，审查并形式化现有英文研究稿中的证明链：嵌套区间产生整数对数型辅助多项式，公共素因子改善增长率与衰减率，再通过高斯整数上的最小多项式和结式，推出每个固定奇数 k ≥ 3 的 pi^k 无理测度显式上界。

最终目标包括：一般转移定理、辅助构造的整性和非退化性、公共因子的普遍整除证明、足够的一侧分析估计、所有固定奇数次数的显式参数方案，以及稿件所列 k = 3, 5, 7, 9 的数值上界。允许采用数学上等价且更适合形式化的证明，允许先完成较弱的闭合结果再恢复原常数，但最终不得以带未证明假设的定理代替完整目标。

优先审查原证明，发现错误或缺口时先定位和修复，不以“忠实翻译稿件”为正确性标准。不要求探索更好的上界，也不要求证明该方法最优。

## 2. 最终数学接口：先明确究竟证明什么

### 2.1 无理测度上界的接口

先清点所固定版本是否已有可用定义和等价定理。若没有，定义一个含义透明的上界谓词，例如：

对每个 epsilon > 0，存在 c > 0 和 Q0，使得所有整数 p、正整数 q ≥ Q0 都满足

    |xi - p/q| ≥ c * q^(-(E + epsilon)).

可优先对所有 p、q 证明，不添加互素限制：本构造的结式估计不需要 p/q 已约分，而这样也便于排除 xi 为有理数。若改用约分后的分数，必须另行处理有理性和定义之间的关系。

证明此谓词蕴含 xi 无理，并且等价于通常所需的 mu(xi) ≤ E。注意“mu ≤ E”一般不能替换成误差在指数恰为 E 时也有统一正下界。

若只取得“对每个 epsilon 的所有充分大分母”的结论，要明确完成到标准无理测度定义的桥接；不能只证明一个未解释的自定义谓词。

### 2.2 抽象辅助多项式假设

固定 k ≥ 2、m ≥ 1、L ≥ 1、G ≥ 0 和 D，并令

    lambda = i*pi/2,
    Delta = D - (k-1)*G > 0.

对 n = L*r、r 趋于无穷，给出 m+1 个 Gaussian-integer 多项式 U[h,n](Y)，次数至多 m，系数方阵可逆。对每个 eta > 0，存在统一阈值，之后所有行 h 及所有 |Y| ≤ 2 同时满足

    |U[h,n](lambda)| ≤ exp(-(D-eta)*n),
    |U[h,n](Y)| ≤ exp((G+eta)*n),
    |T[h,n](Y)| ≤ exp((G+eta)*n),

其中

    U[h,n](lambda) - U[h,n](Y) = (lambda-Y)*T[h,n](Y).

注意：U 的系数在 Gaussian integers 中；T 含 lambda，通常是复系数多项式，不能错误要求 T 也有 Gaussian-integer 系数。

从上述假设严格推出

    mu(pi^k) ≤ m*(D+G)/(D-(k-1)*G).

先完成这个抽象定理，再将具体构造接入。它是重要阶段成果，但只证明它不算整体目标完成。

### 2.3 优先使用足够的一侧速率

主定理实际只需要误差上界、系数上界，以及公共因子的足够大下界，不需要每个量都有精确渐近等式。

若未除因子前有速率 D0、G0，且最终能证明

    对每个 eta > 0，充分大 n 有 Pi[n] ≥ exp((gammaLower-eta)*n),

便可使用

    D = D0 + gammaLower,
    G = G0 - gammaLower.

gammaLower 不必等于真正 gcd 的增长率，也不必等于所选 Pi 的精确增长率。最小化不必要的结论，可显著缩短证明。

## 6. 阶段 P1：先完成可复用的转移定理

这是优先级最高的第一项实质成果。即使分析模块暂时受阻，也能独立产生有价值的闭合定理。

### 6.1 分差恒等式

对次数 ≤ m 的 U 定义

    T(Y) = sum[j=1..m] u[j] * sum[a=0..j-1] lambda^(j-1-a) * Y^a.

直接用有限几何恒等式证明 U(lambda)-U(Y)=(lambda-Y)T(Y)。不使用对可能为零的 lambda-Y 的除法，也不通过复均值定理处理。

### 6.2 Gaussian-integer 范数的离散性

证明非零 Gaussian integer 的复绝对值 ≥ 1。建议通过整数范数 a^2+b^2 证明，再建立复数嵌入下的模长关系。

### 6.3 一般代数值下界

先对任意代数点 y 抽象证明：若 y 被一个最高次系数为 B 的整数环多项式 F 消去，次数 ≤ k，F 的相关根均在给定圆盘，且 U(y) ≠ 0，则由 primitive 最小多项式和结式得到 U(y) 的下界。

在具体应用中令

    theta > 0, theta^k = p/q,
    y = i*theta/2,
    F(Y) = (2^k*q)*Y^k - i^k*p.

必须逐项证明：

1. y 在 Gaussian rationals 上代数；最小多项式次数 d 满足 1 ≤ d ≤ k。
2. 由分式域最小多项式得到 primitive 的 Gaussian-integer 多项式 f。
3. f 在整数环中整除 F。不要把“在分式域整除”直接当成整数环整除。
4. leadingCoeff(f) 整除 2^k*q，从而其模长 ≤ 2^k*q。
5. f 的每个复根也是 F 的根；由模长的 k 次幂相等证明它们全在 |Y| < 2 内。无需显式枚举单位根。
6. U(y) ≠ 0 蕴含 f 不整除 U，从而 resultant(f,U) ≠ 0。
7. 结式属于 Gaussian integers，模长 ≥ 1。
8. 从带重数的根乘积中取出一次 U(y)，利用 d ≤ k 和 deg U ≤ m 得到

       |U(y)| ≥ (2^k*q)^(-m) * exp(-(k-1)*(G+eta)*n).

### 难点：不能偷用“通常次数就是 k”

最终结论覆盖所有有理数 p/q，包括有理幂和二项式可约的情况。用整个 F 与 U 的结式，可能因另一个共轭根上的消失而得到零。必须围绕实际最小多项式证明非零性。

根乘积公式需要兼顾重复根、次数小于 m、以及所选根 y 如何从 multiset 中取出。可用特征零下的可分性简化，但不要额外引入不必要的伽罗瓦理论。

### 6.4 从可逆矩阵选择非零行

若所有 U[h,n](y) 都为零，系数矩阵将非零列向量 (1,y,…,y^m) 送到零。用可逆性排除。

选择的 h 可以依赖 n、p、q；因此所有后续估计必须对 h 一致。

### 6.5 选择 n，并关闭所有量词

固定 eta > 0，满足 Delta-k*eta > 0，取

    r = ceil((m*log(2^k*q)+log 2)/(L*(Delta-k*eta))),
    n = L*r.

必要时增加一个固定下限，保证 r ≥ 1、n 达到所有估计阈值。证明该修改和取整只增加固定常数，不改变 q 的指数。

由小余项与非零代数值的比值 ≤ 1/2，得到

    |lambda-y| ≥ (1/2)*(2^k*q)^(-m)*exp(-k*(G+eta)*n).

随后证明指数恒等式

    (Delta-k*eta)+k*(G+eta) = D+G,

并推出误差下界。最后对任意 epsilon 选择足够小的 eta，而不是写一句未展开的“令 eta → 0”。

### 6.6 从根的距离回到 pi^k

证明 |y| < 2、theta 的存在与正性，以及

    |pi^k-p/q|
      = |pi-theta| * sum[a=0..k-1] pi^(k-1-a)*theta^a
      ≥ 2*pi^(k-1)*|lambda-y|.

对 p/q ≤ 0 或误差 ≥ 1 的分数分别给出简单下界，合并为统一结论。正实 k 次根可用适当的 root API 或存在唯一正解，避免无谓地处理复多值根。

### 验收

抽象转移定理完整构建，无 `sorry`。给出其准确假设，并检查没有把结式下界、非零行或最后的指数运算暗含在未证明字段里。

## 7. 阶段 P2：辅助构造的整性和行列式

### 7.1 参数与有限展开

固定整数 L ≥ 3，0=t[0]<…<t[J-1]<L/2，正整数权重 nu[j]，M=sum nu ≥ 2，m=M-1。令 n=L*r。

区间重复展开并按左端点非降排序：

    I[a]=[alpha[a], beta[a]], beta[a]=n-alpha[a],
    ell[a]=beta[a]-alpha[a].

定义

    Q[n](z)=product[a] product[r in I[a]] (z+r),
    N[n]=sum[a] ell[a],
    d[n]=lcm(1,…,n),
    C[n]=m! * d[n]^m * product[a] ell[a]!.

证明 Q 的次数为 N+M，C 和 d 均为正。

优先在有理数上的局部有限展开定义部分分式系数和 A[h,j,n](x)，然后证明其整性。先不要让这些对象的定义依赖复积分。

可选表示包括形式幂级数或截断展开；先用小样例比较接口后选择一种。后续需要的是有限阶系数、乘积与单位求逆，不需要一般 Laurent 级数理论的全部功能。

### 7.2 整性的两个不同局部估计

对 H[a](z)=ell[a]!/product[r in I[a]](z+r)，在 z=-ell+w 展开。

- 若 ell 在区间内，w*H[a] 的常数是带符号整数二项式系数，u 阶系数的分母由 d[n]^u 清除。
- 若 ell 在区间外，H[a] 的 u 阶系数一般需要 d[n]^(u+1)。其常数不一定为整数。

设极点重数为 mu[ell]。取 (z+ell)^(-j-1) 项时所需总展开阶数至多 mu[ell]-1-j，规则因子数为 M-mu[ell]，因而总分母指数至多

    (mu[ell]-1-j)+(M-mu[ell]) = m-j.

再处理 m!/j! 的整数性，得到 A 的整数系数。

### 难点：分母预算必须在卷积中保持

不能只证明每个因子的单个系数分母受控，然后略过任意乘积的卷积。需要一个可复用引理：在总阶数约束下，所有参与分拆的项有共同清分母幂，有限求和保留整性。(-ell+w)^h 的整数系数只会减少所需展开阶数。

### 7.3 支持与高阶消失

由嵌套性证明

    mu[ell] ≥ j+1 iff ell in I[j].

得到列 j 含因子 x^(n-beta[j])，除去后次数 ≤ ell[j]。

高阶消失可优先用形式级数或截断 jets 表述：将 x=exp(w) 或 x=1+X 代入，证明相应线性组合前 N 个系数为零。用有理函数在无穷远的次数事实证明有限残数和消失，尽量不引入复分析。

若选 x=exp(w)，必须证明 exp(w)-1 的一次项为 1，因此消失阶能转回 x-1。若选 log(1+X)，必须证明使用到的形式复合恒等式。选择一条路线并完成桥接，不能停在尚未连到多项式整除的形式计算。

### 7.4 行列式的非零性

目标为

    det A[n](x) = c[n] * x^(sum[j](n-beta[j])) * (x-1)^N[n],
    c[n] ≠ 0.

次数和消失阶只能给出这个形式，不能排除 c=0。

按相同左端点分块。在一个重复块中，局部单位级数 B(0) ≠ 0，使领先系数的线性泛函与不同阶的除阶乘导数之间存在可逆三角变换。所有块组成合流 Vandermonde 结构。

优先通过核为零证明可逆性：次数 ≤ m 的非零多项式，不可能在不同节点的根重数之和达到 m+1。无需实现庞大的显式行列式乘积公式。

最后代入 x=i，利用 i≠0、i≠1，证明所需方阵可逆。

### 验收

整性与行列式是任意合规参数、任意正 r 的普遍定理，而不是有限 n 的实验结果。

## 8. 阶段 P3：素数赋值、取整单元与公共因子

### 8.1 赋值表示必须先处理零

检查所选 API 对零的约定。有些数值赋值函数在零处的返回值并不是正无穷。不能在没有对应定义的情况下使用“v_p(0)=infinity”。

可选做法：使用带无穷的赋值；显式分开零；或将最终命题改写为整除。目标整数系数的整除命题常比到处传播有理赋值更稳健。

### 8.2 局部赋值引理

对素数 sqrt(n)<p≤n，使用 p^2>n，证明所有非零距离的赋值至多 1，并定义

    w[a] = floor(ell[a]/p)
           - floor((ell-alpha[a])/p)
           - floor((beta[a]-ell)/p).

证明 w[a] 属于 {0,1}。注意后两项可以为负数，必须使用真正的整数 floor，不能偷换为自然数除法。

分别证明：

- 极点因子 u 阶系数的赋值 ≥ w[a]-u。
- 规则因子 u 阶系数的赋值 ≥ w[a]-1-u。
- 规则因子的常数项计算依赖

      floor((s-1)/p) = -floor(-s/p)-1.

与清分母预算合并，得到 A[h,j,n] 在位置 ell 的系数赋值 ≥ sum[a]w[a]+j。最终可放弃额外的 j，取得所有行列通用的因子。

### 8.3 取整函数的有限证书

定义

    W[j](z,y)=floor((L-2t[j])*z)
              -floor(y-t[j]*z)
              -floor((L-t[j])*z-y).

证明周期性、0/1 值，以及在 z=n/(L*p)、y=ell/p 时与局部赋值公式的对应。

可以证明完整最小值 f(z)=min_y sum nu[j]W[j](z,y)，也可以只证明有限分片函数 g(z) 满足

    0 ≤ g(z) ≤ sum[j] nu[j]*W[j](z,y)   对所有 y。

后一种足以产生公共因子，且避免证明证书给出的最小值一定达到。

### 必须强调的端点问题

- 圆周首尾相接的 y 单元不能遗漏。
- z 的临界点来自整数斜率的相遇；不是只有单个端点跨过 0 时才变化。
- 非临界 z 上，端点本身也要覆盖，不能只检查所有开区间的中点后直接宣称全体 y 成立。
- 重复区间应合并为权重，避免把相同端点误判为异常。
- 可在全部 z 临界点上定义 g=0，以安全弱化因子。证明这种弱化确实满足整除要求。
- 要证明每个参数单元内的端点顺序和取整值稳定；一次中点计算不自动代表整个连续区间。

建议建立小型、经证明正确的证书检查器：输入有理 z 分片、整数权重和每片的候选下界，检查器证明下界对整个单元和全部 y 成立。检查器无需搜索最佳参数。

### 8.4 定义因子并系数相除

定义

    Pi[n]=product[prime p, sqrt(n)<p≤n] p^(g(n/(L*p))).

证明 Pi 为正整数并整除每个 A 的每个整数系数。对相除后的多项式，优先构造整数商并证明乘回恒等式，而不是先在复数里相除再断言其为 Gaussian integer。

Pi 同时除小余项、U 的所有系数及其分差，不能只在最终公式中降低一个高度。

### 验收

完成普遍整除定理和一个经检查的有限分片实例。n=345 等有限检查仅作调试，不替代任意 n 的证明。

## 9. 阶段 P4：公共因子的指数下界

### 9.1 将经典素数结论接入正确形式

需要或可由已有结果推出：

    theta(X)=sum[p≤X, p prime] log p = X+o(X),
    log d[n] = n+o(n),
    theta(X) ≤ C*X （充分大 X）。

PNT 库接口可能只给 primeCounting 的极限，需要证明与 theta 的形式转换。log lcm 涉及素数幂，不能将它直接当成 theta；须控制高次素数幂的贡献。

### 9.2 周期分片产生的速率

若 g 在 (a,b)⊂(0,1) 上为整数 v，则每个周期 r 给出形式上的速率贡献

    (v/L) * (1/(r+a)-1/(r+b)).

完整速率可表示为对有限分片和 r≥0 的正项级数。优先使用这个定义；digamma 只是一种求值简写，不是主证明必须的特殊函数。

### 难点：PNT 与无穷周期不能直接交换

若证明完整速率极限，必须先对有限周期使用 PNT，再用 Chebyshev 上界统一控制尾部，最后取周期截断极限。低于 sqrt(n) 的素数和临界点排除也要估计。

一个更轻的可选路线是：只保留有限多个周期，使用正项性得到 liminf 下界。这样可以先建立足够的 gammaLower，免去完整极限及无穷周期的一致尾部证明。其精度是否足以保持原数值，须明确计算验证，不能提前保证。

临界点若需要处理，可利用 {N0/p}=a/d 推出 p 整除 d*N0，结合固定有限个 d 证明总影响至多 O(log n)。也可采用只取开区间且在端点 g=0 的下界形式，减少等号端点的记号负担。

### 9.3 用初等尾界替代 digamma

需要较高精度而又不想验证大量周期时，对

    h(r)=1/(r+a)-1/(r+b),  0<a<b≤1,

证明它为正且单调递减，然后用积分比较控制级数尾部。例如 T≥1 时，可证明尾和在

    log((T+b)/(T+a))

与

    log((T-1+b)/(T-1+a))

之间。必须证明不等式方向、积分值和 T 的边界条件，再用于证书。

也可使用已验证的 digamma API，但应比较其依赖成本。目标是可检查的 gamma 下界，不是为了复现原程序而重建整个 Gamma 理论。

### 验收

得到主构造实际需要的一侧因子指数估计。若使用有限周期下界，记录精度损失；若要最终恢复原数字，继续提高证书精度。

## 10. 阶段 P5：分析估计——预计最重的部分

### 10.1 系数高度上界

从局部展开证明存在只依赖固定参数的 K、B，使所有 h、j、n 满足

    |A[h,j,n](i)| ≤ K * d[n]^m * n^B * 2^(sum[a]ell[a]).

重点不是给出最优 K、B，而是严格证明它们不依赖 n。

固定阶 ≤ m 的倒数线性因子乘积系数，可由 (1-w)^(-d) 的系数控制，随后用固定阶二项式的多项式增长证明。m 固定在 n 的极限之前，因此指数依赖 m 允许存在。

再将有限个系数界转为圆盘 |Y|≤2 上 U 和 T 的统一界。对于 T，lambda 的幂只引入固定常数，因为 |lambda|<2 且次数固定。

### 10.2 积分表示的连接

必须把有限展开定义的 A、U 与分析表示连接：

    R[h,n](i) = C[n]/(2*pi*i) * contourIntegral(z^h*exp((z+n)*lambda)/Q[n](z)).

可以用残数、Cauchy 导数公式，或适合本有理核的专门定理。核的极点、重数、轮廓方向、指数的整函数性均需明确。

直接定义 lambda=i*pi/2 可避免在所有代数引理里携带 principal log 的分支条件；若仍使用 log i，需要单独证明两者相等。

### 10.3 全水平线尾部

对任何固定 Y>1/2，令

    B(Y)=(Y^2+1/4)^2/(Y^2-1/4).

证明对于全部实数 t，包含重复因子在内，

    |Q(-n/2+n*t+i*n*Y)| / |Q(-n/2+i*n*Y)|
       ≥ (1+t^2/B(Y))^(deg Q/2).

证明路线：每个对称偏移 u、-u 成对相乘，比较关于 t^2 的系数；单独处理中心未配对因子。需要先证明所有分母为正，正确处理实指数或平方根。

利用此界证明整个实线积分可积，并由一个与 n 无关的可积函数控制。只证明 t=0 附近的下降或局部鞍点展开不够。

### 10.4 轮廓打开的两个不同极限

先对固定 n 建立有限矩形轮廓恒等式，然后令水平截断趋于无穷；垂直边贡献消失。完成以后，才研究 n→∞。

不能把“垂直边随截断消失”和“关于 n 的渐近估计”混在同一个未经证明的极限交换中。

最终得到

    |R[h,n](i)| ≤ K[h,Y] * n^(h+1) * exp((pi/2)*n*Y)
                 * C[n]/|Q[n](-n/2+i*n*Y)|.

证明 K 对 n 一致；有限多个 h 可取统一常数。

### 10.5 中心指数：Stirling 与黎曼和

对固定相对长度 c∈(0,1] 和 Y>1/2，证明

    log((c*n)!) - sum[r in interval] log|r-n/2+i*n*Y|
       = -n*F_c(Y) + o(n),

其中

    F_c(Y)=(c/2)*log((1+(2Y/c)^2)/4)+2Y*atan(c/(2Y)).

不必一开始追求 O(log n) 的精细误差；o(n) 足以推出指数界。需要证明 c*n 确为整数，含端点的 cn+1 个因子多出的 log n 可忽略。

黎曼和中 Y>1/2 保证 integrand 光滑并远离零。若库中一般黎曼和接口代价较高，可用导数有界的初等误差估计专门证明。

通过一个实变量原函数或求导核验积分值。所有 log 的参数须为正。

### 10.6 优先固定有理高度，不把最优化列为阻塞项

上述衰减界对每个固定 Y>1/2 都成立。优先选取接近现有根区间的有理 Y，并直接验证相应的 D0。

这样核心结果不需要：最优根的存在唯一性、完整凹性分析、根求解算法正确性或鞍点根的精确表示。

现有数值有严格舍入余量，因此原则上可以寻找足够接近的有理高度保留目标比较；实际是否保留每个界须由新证书确认。不能仅因原 Arb 球很窄就宣称已经验证替代高度。

### 验收

得到对 n=L*r、全部行及整个圆盘一致的误差与高度估计，并接入 P1。到这里应当先得到至少一个真正闭合的上界实例；若它稍弱，明确标记为中间结果，继续恢复计划目标。

## 11. 阶段 P6：数值证书与 pi^3 的完整闭合

### 11.1 证书最小内容

证书使用精确整数和有理数，至少包含：

- L、t、nu、k、m。
- z 的有理分片及每片经证明的因子指数下界。
- 一个固定有理 Y>1/2。
- pi、log、atan 等数值界所用的有理输入、截断阶数和余项界。
- gammaLower、DLower、GUpper 的有理比较。
- 正 gap，以及最终指数严格小于目标有理数的证明。

原 JSON 的 Arb 字符串可辅助生成候选界，但不能直接当作真理导入。

### 11.2 必须闭合的超越函数界

可复用库中的严格数值界。若需补充，选择简单、有显式余项的级数或区间缩放：

- pi 的有理上下界及其证明。
- log 的参数缩放与快速收敛展开。
- atan 的范围缩放或适用区间内的交错级数余项。
- 级数尾和的有理/对数界。

对所有区间操作证明单调方向。特别注意：因子下界提高 D、降低 G；分母 Delta 必须先证明正，再做分式比较。

### 11.3 严格不等式与声明

用精确有理数 1203973/1000 表示目标。先证明一个形式上正确的上界 E，再证明 E < 1203973/1000，最后推出 mu(pi^3)<1203.973。

若采用 DLower、GUpper，证明它们足以单调控制最终公式；不要直接将每个量分别舍入后代入而省略正性和单调性条件。

可用交叉相乘后的多项式不等式减少除法和区间依赖：在已证明 gap>0 后，验证

    m*(D+G) < target*(D-(k-1)*G).

### 验收

第一个完整实例没有未证明的解析假设、素数渐近假设或外部数值假设。最终定理包含的只是标准定义与固定参数，公理依赖经过核查。

## 12. 阶段 P7：一般奇数次数与更高次数实例

### 12.1 固定形状，权重统一缩放

使用 L=69、t[j]=j、j=0,…,11，基本权重 v[0]=6、其他为 1，nu[j]=s*v[j]。

证明

    M=17s, m=17s-1,
    c[j]=1-2j/69,
    S=sum[j]v[j]*c[j]=347/23.

因子证书随权重线性缩放。无需为每个 s 重跑连续单元分解，更不需要展开 m 阶矩阵。

### 12.2 免求根的显式参数

以已证明可用的基本因子速率 gammaStar 定义

    gStar = 17 + S*log 2 - gammaStar,
    AStar = sum[j]v[j]*c[j]*log(c[j]),
    dStar = S*log(S/(pi/2)) - AStar - 17 + gammaStar.

gammaStar 可以采用已证明的精确基本速率，也可以采用统一的一侧下界；若使用下界，以上三个定义和随后所有估计必须一致更新。

取试探高度 Y0=s*S/(pi/2)，利用 x≥0 时

    atan(x) ≥ x-x^3/3,
    log(1+x^2) ≥ 0,
    sum[j]v[j]*c[j]^3 ≤ S,

证明

    D ≥ Dunder[s] = s*(S*log s+dStar)+1-(pi/2)^2/(12*s*S),
    G = s*gStar-1

或证明足够的 G 上界。确保 Y0>1/2，才能调用已有积分估计。

选择

    s[k]=max(1, ceil(exp(((k-1)*gStar-dStar)/S + 1))).

形式化 ceil、log、exp 的单调关系，得到

    Dunder[s[k]]-(k-1)*G[s[k]]
       ≥ s[k]*S+k-(pi/2)^2/(12*s[k]*S)>0.

证明 G≥0 所需的 gammaStar 上界，例如由基本因子指数 ≤17 得到 gammaStar≤17；不能把一侧下界 gammaStar 当成自动已知的完整极限使用。

### 12.3 注意两种参数变化

对每个固定 k，先选 s[k]，随后才令 n→∞。不需要证明 n 与 k 同时变化的统一误差估计。

同时，定理应对所有固定奇数 k≥3 量化，而不是只列有限表格。P1 可对所有 k≥2 证明，奇数限制只在最终应用中保留。

### 12.4 更高次数的数值推论

分别实例化 s=259、5871、131354，复用固定形状证书。证明四个表格结论，不依赖生成百万维矩阵，也不需要证明参数在该形状内最优。

### 验收

一般奇数幂定理和四个数字均从已闭合的构造、分析与证书定理导出，没有隐藏的“对所列 k 已数值观察到成立”假设。

## 13. 高风险清单：优先检查，不要留到集成时

| 风险 | 常见错误 | 正确处理 |
|---|---|---|
| 最小多项式 | 用整个二项式结式，忽略它可能可约 | primitive 最小多项式，证明实际次数 ≤k |
| leading coefficient | 分式域整除直接推出整数环整除 | 明确使用 Gauss 引理与 primitive 性 |
| 正则局部因子 | 把常数误当整数 | 预算中保留额外一幂 d[n] |
| 赋值的零 | API 的零值与数学约定不一致 | 显式分零或使用整除谓词 |
| 负数 floor | 用 Nat 除法取代 floor | 在整数/有理数中证明有符号恒等式 |
| 重复端点 | 普通 Vandermonde 不适用 | 分块三角变换与总根重数 |
| 行列式常数 | 次数和消失阶不能排除零多项式 | 领先系数矩阵非退化证明 |
| 圆周分片 | 中点检查遗漏端点或回绕单元 | 检查器证明连续单元及边界覆盖 |
| 统一高度 | 阈值依赖 y 或选择的行 | 对整个圆盘和全部有限行统一量化 |
| 无穷周期 | 直接交换 PNT 与无穷求和 | 有限截断加统一尾界，或只做下界 |
| 轮廓尾部 | 只有局部鞍点近似 | 全实线可积控制及固定 n 的轮廓极限 |
| 率的单位 | n=L*r，却误用 r 的速率 | 全部速率明确以 n 归一化 |
| 公因子应用 | 只降低系数高度 | 误差、系数和分差一致相除 |
| 数值证书 | 将 Arb 输出当成 Lean 已证明 | 有理数据和经证明正确的检查器 |
| 大参数计算 | 展开百万维辅助矩阵 | 使用一般符号定理和固定形状证书 |
| 最终量词 | 把 eta→0 当成自动连续性 | 对每个 epsilon 明确选择 eta |

## 14. 估计工作量时的正确口径

不能按“英文稿 22 页”估算 Lean 工作量。应分别记录：

- 数学上是否已有充分证明；是否需要修补。
- 核心引理是否已有库接口。
- 已有结论到当前表示的桥接成本。
- 数值证书精度、检查器性能和证明对象大小。

大致难度分布：

- 分差恒等式、最后的实数指数运算：较低到中等。
- 最小多项式、Gauss 引理、结式乘积的组合：中等到较高。
- 局部展开整性、赋值卷积及行列式：较高，但结构稳定、可拆分。
- 素数结论的接口和公共因子速率：高度取决于依赖库。
- 复轮廓表示、全线积分与渐近桥接：最高风险，可能占总体主要工作量。
- 具体数值：数学难度较低，证书设计和内核检查效率可能成为工程难点。

P0 结束后再根据实际库缺口修订工作量判断，不给未经验证的天数或代码行数承诺。

1. 阅读第 5 节转移证明，写出抽象定理的准确 Lean 类型草案。
2. 检查本机 Lean 与库环境，选定版本，建立独立工程和审计文件。
3. 首先证明分差恒等式、非零 Gaussian integer 的模长下界，以及矩阵可逆推出存在非零行。
4. 清点并打通 primitive 最小多项式到结式下界的接口，这是第一项核心难点。
