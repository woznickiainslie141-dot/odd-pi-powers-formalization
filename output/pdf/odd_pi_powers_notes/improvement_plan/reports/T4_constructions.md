## 0. 结论速览（随实验更新）

- 结构性下限 E_k ≥ m 来自"首项系数的 m 次方"。任何突破都必须让辅助多项式在 λ 上**稀疏**（只含 λ^{kj}），
  或让 k−1 个共轭值也变小。下面三条路线分别对应：(1) 稀疏 Type I；(2) 固定次数 Type II；(3) 二元形式 q·β(3)−p。

## 1. 路线 1：稀疏 Hermite–Padé（只含 (log x)^{kj}）

### 1.1 为什么 k=2（x=−1）能"免费消元"，奇数 k 不能  [proved]

- k=2、x=−1：A_j(−1)∈Z，λ'=iπ。R(−1)=Σ_j A_j(−1)(iπ)^j，取实部
  Re R(−1)=Σ_{j 偶} A_j(−1)(−1)^{j/2}π^j 是 Z[π²] 中的稀疏形式，且 |Re R|≤|R|。
  关键：复共轭 σ 是 **C 上的等距域自同构**，固定系数（Z 中）并把 λ' 送到 −λ'，所以 σ(R)=conj(R) 与 R 同样小。
- 奇数 k≥3：需要一个映射固定 Q(i) 系数、把 λ 送到 ζ_kλ、且保持"小"（|σ(z)|≍|z|）。
  保持绝对值的域自同构必连续，而 C 的连续域自同构只有恒等和复共轭（阶 ≤2）。所以**不存在**这样的 σ；
  "把 R 在 ζ_kλ 处的值也变小"只能靠新的构造条件，而不是对称性。这就是原框架里 −(k−1)G 损失的来源（共轭点 ζ^l y 处 U 只能用高度界）。
- 对 k=2 在 x=i（而不是 −1）也不免费：系数在 Z[i]，conj(R(i)) 是 x=−i 处的另一个形式，不再是同一多项式的值。

### 1.2 在 ζ_k 轨道上平均 / 把 Q 换成 ζ_k 不变乘积：系数不再代数  [proved]

- 平均：Σ_l R(e^{ζ^l w}) 只在"系数不依赖 w"时才等于 k·Σ_{j≡0} 的稀疏部分。
  Type I 形式的系数是 A_j(x)=A_j(e^w)，旋转 w→ζw 把求值点变成 x_l=e^{ζ^l λ}=i^{ζ^l}。
  由 Gelfond–Schneider（i 代数≠0,1，ζ_k (k≥3) 代数且非有理），i^{ζ_k} 超越。故平均后的系数 A_j(x_l) 不在 Q̄ 中。[proved，用 literature: Gelfond–Schneider]
- ζ_k 不变核：若 f(ζz)=f(z)，则 F(w)=∮f(z)e^{zw}dz 满足 F(ζw)=ζ^{-1}F(w)，故 F 的 Taylor 展开只含 w^{j}, j≡−1 (mod k)——**在 w 上确实稀疏**。
  但 f 的极点成 ζ 轨道 z_0=−ℓζ^r，留数给出 P(w)e^{z_0 w}，在 w=λ 处 e^{−ℓζ^rλ}=i^{−ℓζ^r} 超越。
  这是 Hermite 证 e 超越的指数多项式框架，不给出 Q(i)-系数的 π^k 形式。[proved]
- Meijer G / Mellin–Barnes：被积函数为 Γ 比值时，留数级数在 x=i 处一般给出非终止超几何级数值（非代数）；
  若要求终止，被积函数退化为有理函数，回到原稿的 Q_n 族（稠密 Type I）。结论：**稀疏性不能来自积分核的形状，只能来自额外线性条件**。[heuristic，未对所有 Γ 比值证明]

### 1.3 线性代数版稀疏 Type I（实验，见 1.4）

系统 (1, L^k, L^{2k}, …, L^{km'})，L=log x，P_j∈Z[x] 次数 ≤ n，要求在 x=1 处零点阶 (m'+1)(n+1)−1。
若存在、且 m'+1 个形式线性无关，则在 x=i 得到 Z[i] 系数、关于 π^k 的 m' 次多项式形式，
转移只需有理点 p/q 处的 Liouville 下界 q^{−m'}，**没有 (k−1)G 损失**：
  μ(π^k) ≤ m'(δ+κ)/δ，m' ≈ m/k。
代价：零点阶从 (m+1)n 降到 (m'+1)n ≈ (m+1)n/k，且系数不再有积分表示（分母可能非指数增长）。
